# Soc-in-a-Box: Mini-SOC in a box 

LabShop is a small online shop with one web server and one staff PC and no security monitoring.
This project builds a small Security Operations Centre (SOC) around **Wazuh**, step by step.
This README covers **Week 1: build the lab and deploy Wazuh**.

## Start and stop the lab (in this order)

**Start**
1. Start **siem-host**. Wait until it has booted and has its IP.
2. On siem-host: `cd ~/wazuh-docker/single-node && docker compose up -d`
3. Check: `docker compose ps` shows three containers *Up*. Wait 2-3 minutes for the indexer.
4. Open `https://10.10.10.10` from the Dell and log in.
5. Start **ubuntu-web**, then **win-client**. Both agents reconnect on their own. Check Endpoints in the dashboard.

**Stop**
1. Shut down **win-client** and **ubuntu-web** first.
2. On siem-host: `docker compose stop` (**not** `docker compose down -v`: `-v` deletes the volumes, which means your alerts and agent registrations).
3. Shut down siem-host (`sudo shutdown now`).

## Path of one event: from the endpoint to the alert (V2)

Example: failed SSH login on ubuntu-web.

1. **Endpoint:** `sshd` writes `Connection reset by invalid user ... [preauth]` to the system journal.
2. **Agent (ubuntu-web):** the Wazuh agent reads the journal and sends the log line to the manager on **port 1514** (the agent first enrolled on **1515**).
3. **Manager:** analysisd **pre-decodes** the line (timestamp, host, program `sshd`), the **decoder** extracts the fields (`srcip`, `dstuser`), and the **rules** engine matches rule 5710 and gives it a level.
4. **Manager to indexer:** the alert is written to `alerts.json` and shipped to the **indexer** (port 9200).
5. **Indexer:** stores it in the `wazuh-alerts-4.x-YYYY.MM.DD` index.
6. **Dashboard** (port 443): queries the indexer and shows the alert in Discover. The dashboard talks to the manager API on 55000 for agent and management data.

## Security hygiene

- No password, key or certificate is committed. See [.gitignore](.gitignore).
- Check before every commit: `git ls-files | grep -Ei '\.(pem|key|crt|env)$|internal_users|password'` must print nothing.
- Attack tools are used only against the lab VMs on the isolated host-only network.
